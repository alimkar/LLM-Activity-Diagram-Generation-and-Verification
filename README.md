# LLM-Activity-Diagram-Generation-and-Verification

Research artifacts for LLM-based UML Activity Diagram Generation and Verification



This repository contains the research artifacts associated with the study:



\*\*Generating and Verifying UML Activity Diagrams with Large Language Models:

An Empirical Study\*\*



The repository provides the experimental materials used for the generation

and verification of UML activity diagrams.



\## Repository Contents



\### Activity Diagram Generation Prompts

Contains the prompt templates used for the activity diagram generation experiments.



\### Gold Standard Solutions

Contains manually constructed Gold Standard activity diagrams and their

corresponding PlantUML representations.



\### Source Code

Contains the source code and experimental artifacts associated with:



\- Error Taxonomy

\- Activity Diagram Generation

\- Activity Diagram Verification



\## Experimental Dataset



The study uses 15 software requirements selected from the PURE dataset,

covering low, moderate, and high behavioral complexity.



Five prompting strategies were investigated:



1\. Standard Zero-shot

2\. Standard One-shot

3\. Standard Few-shot

4\. Chain-of-Thought Zero-shot

5\. Chain-of-Thought Few-shot



Four verification techniques were investigated:



1\. Human-in-the-Loop (HITL)

2\. ClarifyLLM

3\. HITL + MCeT

4\. ClarifyLLM + MCeT



\## Reproducibility



The repository provides the prompts, Gold Standard activity diagrams,

generated diagrams, and source code used in the experimental study to

support reproducibility and future research.



\## Data Provenance



The requirements used in this study were selected from the PURE

(PUblic REquirements) dataset. Please refer to the original PURE dataset

for its applicable terms of use.
